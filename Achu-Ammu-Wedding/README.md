# Achu-Ammu Wedding Invitation

## Quick Start
1. Open `index.html` in your browser
   - Windows: `start Achu-Ammu-Wedding/index.html`
   - Or drag `index.html` into Chrome or Firefox

## Features
- Parallax storytelling across intro, wedding, and reception
- Romantic cloud, bird, petal, and lighting effects
- Indian wedding styling with mandap and warm gold tones
- Responsive layout for phone, tablet, and laptop
- Pure HTML, CSS, and JavaScript

## Sections
1. Groom and bride introduction
2. Couple meets in the mandap
3. Reception celebration
